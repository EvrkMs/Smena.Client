# Бэклог Smena.Client

Зафиксированные решения по итогам аудита кода (июль 2026). Реализация — по мере надобности.

## Согласовано, ждёт реализации

### ErrorBoundary: восстановление без потери состояния
«Попробовать снова» в ErrorBoundary пересоздаёт всё React-дерево — состояние всех
вкладок (введённые суммы, строки отчёта, запущенные сценарии) сбрасывается в ноль.
Проблема знакома по опыту разработки панели — сталкивались часто.
Направление: либо отдельный boundary на каждую вкладку (падает одна — остальные
живут), либо вынести состояние форм из компонентов (по аналогии с lib/appData.ts /
usePersistedState), чтобы remount его не терял.

### №11: взаимоисключающие чекбоксы в «Авансе»
«Безналичный расчёт» и «Списать из сейфа» не могут быть включены одновременно —
при установке одного второй должен сниматься автоматически (как радио-поведение,
но оба могут быть выключены).

### №12: причина недостачи по сейфу
Сейчас `whyMinus` («Причина недостачи») требуется только при минусе по кассе.
Сделать:
- требовать причину и при недостаче по сейфу;
- не отправлять устаревший `whyMinus` из localStorage, когда недостачи уже нет.

## Отложено сознательно

- **Синхронизация удаления сотрудников** (№4) — сервер отклонит отчёт с удалённым
  сотрудником; честное решение требует эвентов и переделки архитектуры
  сервер+клиент. Не делаем.

## Сделано (2026-07)

- Отмена фото-сценария из UI — кнопка «Отменить» у прогресса (Raport/Expense),
  мост рвёт gRPC-стрим, сервер прекращает ожидание сам.
- Константы смены приходят с сервера (GrpcConstantsService), локальный
  ShiftConstants — только фолбэк при недоступности сервера.

## Мелочи (низкий приоритет)

- `maxDigits={6}` захардкожен в Advance/Expense/Coming — брать `maxAmountDigits`
  из констант, как в Raport.
- Поиск склада: `WarehouseService.SearchItemsAsync` глотает ошибки (возвращает
  `[]`), плюс нет защиты от гонки ответов при быстром вводе.
- Клиент не сверяет сумму аванса/расхода «из сейфа» с текущим балансом сейфа
  (сервер проверяет, но можно предупреждать раньше).

## Памятка

- 0 часов у сотрудника в отчёте — это фича (сотрудник может взять напиток, не
  выйдя на смену), не валидировать.
- DevTools и браузерные хоткеи WebView2 отключены сознательно (MainForm.cs):
  F5 посреди фото-сценария сбрасывал JS-состояние при живом C#-сценарии.
- Конфиг подключения: %LOCALAPPDATA%\Smena.Client\appsettings.json (создаётся
  формой первого запуска, перекрывает appsettings.json рядом с exe).
